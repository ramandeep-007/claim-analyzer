# Claim Analyzer

An AI-powered system for analyzing claims using evidence and transparent reasoning.

## 🎯 Goal

The goal of this project is to build a system that can take a claim, retrieve relevant evidence, analyze the relationship between the claim and the evidence, and provide a transparent explanation.

## 🚧 Project Status

Currently in development.
